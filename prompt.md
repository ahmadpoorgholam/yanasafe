# YanaSafe — product brief (POC)

YanaSafe is an open-source proof of concept for safer online dating through:

1. Automated profile assessment (score, flags, suggestions)
2. Community safety reports open to everyone
3. Practical safety tips (public meetings, slow trust, no hotel/account access handovers)

## Positioning

- Inclusive: not women-only (contrast with apps like Tea without disparaging them)
- Independent place to research and talk about dating safety
- Honest POC: mock analysis by default; Firebase scaffolding; incomplete PWA polish

## Stack

Next.js 14 App Router, React 18, TypeScript, Tailwind, shadcn/ui, Firebase, optional Perplexity.

## Design notes

Existing sage-green theme and component library are preserved. Prefer clarity over marketing hype. Avoid claiming E2E encryption, GDPR certification, or live user metrics that are not real.
